# 🛒 CodeAlpha E-commerce Store

A full-stack e-commerce web application built as part of the CodeAlpha internship task.  
The project allows users to browse products, add them to cart, and place orders with authentication.

---

## 🚀 Features

- Product listing page with images
- Product detail page
- Shopping cart (session based)
- User registration & login system
- Order placement system
- Order cancellation (delete functionality)
- MongoDB database integration
- Responsive UI using Bootstrap

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, Bootstrap, EJS  
- Backend: Node.js, Express.js  
- Database: MongoDB (Mongoose)  
- Authentication: Express Session, bcrypt
